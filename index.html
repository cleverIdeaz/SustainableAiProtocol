The problem

No standard. No data. No button.

AI energy use is real and growing. But it's completely invisible to users and unmeasured at the interaction level.

For developers

One line to integrate.

Add the SAP button to any AI interface. The script auto-attaches to prompt inputs and tracks interactions.

Embed the SAP button 
<!-- Add to any page with an AI prompt input -->
<script src="https://sustainableaiprotocol.com/sap-embed.js"></script>
Manual tracking API 
// Track an AI interaction manually
fetch('https://sustainableaiprotocol.com/api/track', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'anthropic/claude-sonnet',
    tokens: 1200,
    type: 'text',
    user_id: 'anonymous'  // or your app's user ID
  })
});

// Get global stats
fetch('https://sustainableaiprotocol.com/api/stats')
  .then(r => r.json())
  .then(data => console.log(data.total_count, data.total_kwh));
