Quick Start Guide

# Install SAP SDK
pip install sap-sdk

# Basic usage
from sap_sdk import SAPTracker

tracker = SAPTracker(api_key="your_api_key")

# Track an AI interaction
tracker.track(
    prompt="What is sustainable AI?",
    model="gpt-4",
    tokens=50,
    energy_kwh=0.0025
)

# Get global stats
stats = tracker.get_stats()
print(f"Total prompts: {stats['total_prompts']}")

#!/bin/bash

# SAP tracking function
track_sap() {
    local prompt="$1"
    local model="$2"
    local tokens="$3"
    
    curl -X POST https://sustainableaiprotocol.com/api/track \
      -H "Content-Type: application/json" \
      -d "{
        \"prompt\": \"$prompt\",
        \"model\": \"$model\",
        \"tokens\": $tokens,
        \"energy\": $(echo "$tokens * 0.001" | bc),
        \"userId\": \"$(whoami)\"
      }"
}

# Usage
track_sap "What is sustainable AI?" "gpt-4" 50

Real-world Examples

Here are some practical examples of how to integrate SAP tracking into your applications: 
# Example 1: Track OpenAI API calls
import openai
from sap_sdk import SAPTracker

tracker = SAPTracker(api_key="your_sap_key")

def chat_with_tracking(prompt):
    response = openai.ChatCompletion.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}]
    )
    
    # Track the interaction
    tracker.track(
        prompt=prompt,
        model="gpt-4",
        tokens=response.usage.total_tokens,
        energy_kwh=response.usage.total_tokens * 0.001
    )
    
    return response.choices[0].message.content
# Example 2: Batch tracking
import pandas as pd
from sap_sdk import SAPTracker

tracker = SAPTracker(api_key="your_sap_key")

# Load your AI interaction data
df = pd.read_csv('ai_interactions.csv')

# Track all interactions
for _, row in df.iterrows():
    tracker.track(
        prompt=row['prompt'],
        model=row['model'],
        tokens=row['tokens'],
        energy_kwh=row['energy_kwh']
    )

API Endpoints

POST /api/track
Track an AI interaction with energy and CO₂ calculations.
GET /api/stats
Get global sustainability statistics and metrics.
POST /api/optimize
Optimize prompts for maximum sustainability and efficiency.
GET /api/alternatives
Get green AI alternatives for your current model.
GET /api/environmental
Get real-time environmental data and air quality metrics.
